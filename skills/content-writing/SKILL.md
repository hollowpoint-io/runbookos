# Content Writing

## Purpose

Create commercially useful, search-aware content for ecommerce, service pages, product listings, collections, blogs, and proposals.

## Use When

- Use this skill when drafting collection, product, service-page, or blog copy.
- Use this skill when rewriting existing pages in the client's voice.
- Use this skill when meta titles and descriptions need writing alongside body copy.
- Use this skill when humanizing or de-AI-ifying existing drafts.
- Do not use when keyword evidence does not exist yet — run seo-research first, then draft.
- Do not use for creating Shopify listings or uploading collection content — use shopify-product-listing or shopify-collection-content.

## Research Phase (always first)

1. Read the client dashboard and brand context.
2. Pull 2-3 existing client pages of the same type — the client's live copy is the voice benchmark for tone, structure, and length.
3. Confirm research data exists (keyword targets, SERP notes, briefs). If missing, state the gap and ask whether to draft without it or run seo-research first.
4. Collect concrete product/service facts from source material before drafting — no facts, no copy.

If research contradicts the task's premise, stop and report before continuing — do not build on a broken premise.

## Workflow

1. Complete the research phase above.
2. Identify the page type, audience, market, and conversion goal.
3. Draft in the client's voice.
4. Add internal links, calls to action, and FAQs only where they serve the page intent.
5. Avoid generic AI filler, unsupported claims, and unverified compliance statements.
6. Save drafts in the relevant client workstream folder.

## Output

Content should include:

- Title/H1
- Meta title
- Meta description
- Body copy
- FAQ where useful
- Internal link suggestions
- Source notes when research was used

## Quality Bar

- Lead with the user's intent, not a generic intro.
- Use concrete product/service details from source material.
- Keep claims proportional to evidence.
- Use local spelling, units, and terminology.
- Prefer short paragraphs and scannable sections for ecommerce/service pages.
- For collection and product copy, include buyer guidance, compatibility/selection criteria, and differentiators when known.
- For blogs/guides, include an outline, draft, source notes, and suggested internal links.

## Effort & Model Tiers

- Gathering voice examples, scanning briefs and research data → `fast`
- Routine product/collection descriptions at volume → `balanced`
- Pillar pages, brand-voice work, anything high-stakes client-facing → `deep` (manifest default)

Manifest `modelTier` is the default for the skill's core work. Caller effort modes map: quick → `fast` + minimal scope; standard → manifest tier; deep → `deep` + full research phase + verification evidence.

## Approval Boundaries

**Autonomous (no approval needed):**
- Reading client examples and research data
- Drafts and revisions in client workstream folders
- Dashboard and daily memory updates

**Approval required before execution:**
- Publishing to any live platform (Shopify, CMS, blog)
- Sending drafts to the client or any external party

**Never:**
- Publish without an explicit publish instruction naming the destination
- Overwrite existing live copy without saving the old version first

## Safety

- Do not make medical, financial, legal, or regulatory claims without source support.
- Mark uncertain claims.
- Use the local market's spelling and terminology.
