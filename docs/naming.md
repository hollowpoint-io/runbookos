# Naming

Working name: **RunbookOS**.

## Why This Name

The product is not a chatbot. It is a structured execution layer for AI-assisted operations.

RunbookOS suggests:

- Repeatable work
- Operational discipline
- Agency/client execution
- A system agents can follow

## Positioning Line

RunbookOS is a model-agnostic AI operating workspace for ecommerce operators, agencies, and fractional digital engineers.

## Names To Avoid

Avoid names that imply the product is only:

- A chatbot
- An ecommerce app
- A CRM
- A Claude wrapper
- A Codex wrapper
